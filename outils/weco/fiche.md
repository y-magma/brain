# Fiche — Weco

- **Nature** : outil-magma
- **Attention** : essentiel *(proposition — voir [`../../TRI.md`](../../TRI.md))*
- **Tags** : data, viz
- **Slogan** : « Voir pour comparer — pas pour tout décider. »
- **Repo** : [y-magma/weco](https://github.com/y-magma/weco)
- **Pages** : [y-magma.github.io/weco](https://y-magma.github.io/weco/) (`baseURL` `/weco/`)

## Quoi

Boîte à outils web : profils, séries temporelles, comparaisons multi-pays, sources (WID, OECD, World Bank). Transformations **visibles** ; URL partageable par vue.

## Quelles idées Brain il peut catalyser

| Idée / chantier (ex.) | Comment Weco aide |
|----------------------|-------------------|
| Faits vs slogans chiffrés | Ancrer un claim sur une vue tracée |
| Sortir du populisme | Montrer distributions, pas une moyenne menteuse |
| Multi-échelle | Pays × temps × tranches |
| Science / open data | Sources officielles, pas PDF jetable |

## Ce qu’il ne catalyse pas (honnêteté)

- Steelman complet / atlas de slogans culturels  
- Fiction absurde / spectacle duel  
- « Tout le débat public »  

→ D’**autres outils Magma** pourront porter d’autres briques.

## Tension fertile (à débattre ailleurs)

« Voir l’inégalité, est-ce déjà agir ? » — question utile, mais ce n’est **pas** la fiche produit Weco ; c’est un **exemple de débat** qu’on peut *brancher* sur Weco (voir [`exemples.md`](exemples.md)).
