# Inbox — étincelles rapides

> **Vélo, marche, douche.** Une phrase. Pas un chantier.

## Pourquoi

Créer un dossier `chantiers/…` = trop lourd pour une étincelle.  
L’archive = pause, pas capture.  
**Ici** = file d’attente **avant** de décider *où* ça va.

## Comment (30 secondes)

1. Copier [`_gabarit-etincelle.md`](_gabarit-etincelle.md)  
2. Nommer `AAAA-MM-JJ-slug-court.md`  
3. Remplir : **une phrase** + **nature** (`idée-brain` **ou** `outil-magma`) + tags optionnels  
4. Plus tard : trier → chantier / `outils/` / cas / archive / poubelle

## Nature — ne pas coller

| Nature | Ça veut dire | Suite typique |
|--------|--------------|---------------|
| **idée-brain** | Réflexion, slogan, tension, méthode atelier | → `chantiers/<sujet>/` |
| **outil-magma** | Produit **nommé** qui catalyserait *une partie* des idées | → `outils/<nom>/` |
| **exemple-question** | Débat cobaye adaptable | → `chantiers/banc-essai-debats/cas/` |
| **?** | Pas sûr | Rester ici jusqu’au tri |

**Test outil Magma :** « Est-ce que ça a un **nom de produit** et un **cas d’usage** pour *certains* utilisateurs — sans prétendre porter *toutes* les idées du Brain ? »  
Si non → c’est une **idée-brain** (même si ça parle d’outils).
