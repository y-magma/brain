# Seed — IA et UX comme matières premières

- **Slogan** : « IA intégrée, pas collée. »
- **Priorité** : haute

## La tension

L’IA ici n’est pas seulement « atelier vs juge » (voir archive).  
On peut bâtir des **interfaces nouvelles** (LLM, agents, UI multi-échelle). S’en servir pour inventer l’outil Magma — pas recopier un forum.

Tension fertile avec [`../simplicite/`](../simplicite/) : puissance ≠ blabla.

## Faits / valeurs / hypothèses

- **Faits** : LLM changent le possible UI (2020s).
- **Valeurs** : humains décident ; clarté > gadget.
- **Hypothèses** : UX+IA au cœur débloque des formes impossibles « à la main seule ».
