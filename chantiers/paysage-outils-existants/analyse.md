# Analyse — outils existants (débat, démocratie, savoir)

- **Date** : 2026-07-27
- **Nature** : cartographie (faits = existence des outils ; valeurs/hypothèses = lectures Magma)
- **Incertain** : exhaustivité ; certains produits évoluent vite — re-vérifier les URLs.

> Magma n’est **pas** « mieux que tous ceux-là ».  
> C’est une **famille** qui peut *emprunter*, *relier*, ou *laisser faire* ce qui marche déjà.

Légende **↔ Magma** :

| Symbole | Sens |
|---------|------|
| **proche** | Couvre une brique Magma / Brain |
| **partiel** | Chevauche, mais autre métier |
| **loin** | Utile à connaître ; pas le même job |
| **outil Magma** | Déjà dans [`../../outils/`](../../outils/) |

---

## Synthèse ultra courte

| Besoin Magma / Brain | Qui le fait déjà (en gros) | Trou fréquent |
|----------------------|----------------------------|---------------|
| Argument pour/contre structuré | Kialo, DebateGraph, Argdown | Peu de slogans-culture + effet psychique |
| Consensus / fractures à grande échelle | Pol.is | Peu d’encyclopédie permanente des phrases |
| Savoir vivant versionné | Wikipédia | Peu de steelman démocratique assumé |
| Décision de groupe | Loomio | Pas un atlas public de slogans |
| Participation institutionnelle | Decidim, Consul | Lourdeur ; peu « titiller » |
| Annotation dans le flux | Hypothes.is, Community Notes | Pas machine à penser complète |
| Q&A expertise | Stack Overflow | Pas démocratie / valeurs |
| Viz inégalités | **Weco** (Magma) | Pas débat steelman |

## 1. Argument mapping & débat structuré

### [Kialo](https://www.kialo.com/) · [Kialo Edu](https://www.kialo-edu.com/)

Débats en arbre pour / contre sous une thèse ; très utilisé en pédagogie.

| | |
|--|--|
| **Pour** | Steelman forcé par la structure ; lisible ; scale pédagogique |
| **Contre** | Peut figer le binaire ; peu d’« effet psychique » / culture du slogan ; UI « sérieux école » |
| **↔ Magma** | **proche** de la brique débat / atlas — Magma peut s’en inspirer sans le recopier ; ajouter slogans, fiction, jugement multi-dimensions |

### [DebateGraph](https://debategraph.org/)

Cartes d’arguments visuelles (issues / positions / arguments — lignée IBIS).

| | |
|--|--|
| **Pour** | Graphe riche ; vue d’ensemble |
| **Contre** | Courbe d’apprentissage ; adoption grand public limitée |
| **↔ Magma** | **proche** méthode ; Magma *pour tous* / plat → pas forcément le même UX |

### [Argdown](https://argdown.org/)

Langage texte → cartes d’arguments (devs / chercheurs).

| | |
|--|--|
| **Pour** | Versionnable (git-friendly) ; précis |
| **Contre** | Pas grand public ; pas produit démocratie |
| **↔ Magma** | **partiel** — cousin du Brain Markdown ; pas un outil citoyen Magma |

### [ProCon.org](https://www.procon.org/)

Dossiers pour/contre éditorialisés sur sujets US.

| | |
|--|--|
| **Pour** | Clair ; entrée grand public |
| **Contre** | Curaté US-centré ; peu collaboratif vivant |
| **↔ Magma** | **partiel** — ton « fiche » proche d’un atlas curaté MVP |

## 2. Opinion clustering & délibération à l’échelle

### [Pol.is](https://pol.is) · [CompDem / open source](https://github.com/compdemocracy/polis)

Statements + votes ; ML qui cartographie consensus et minorités (ex. vTaiwan).

| | |
|--|--|
| **Pour** | Scale ; moins de fil toxique ; révèle accords surprenants |
| **Contre** | Pas une encyclopédie durable des slogans ; facilitation humaine souvent nécessaire |
| **↔ Magma** | **proche** « questions refusées / fractures » — excellent *outil Magma possible* ou intégration ; ne remplace pas atlas / fiction |

### MIT Deliberatorium ([aperçu recherche](https://deliberatorium.org/homepage/research.html))

Argumentation crowdsourcée pour problèmes complexes (Klein et al.).

| | |
|--|--|
| **Pour** | Théorie solide ; anti-redondance |
| **Contre** | Peu grand public ; recherche / déploiement limité |
| **↔ Magma** | **proche** intellectuellement ; **loin** comme produit grand public immédiat |

## 3. Savoir collaboratif

### [Wikipédia](https://www.wikipedia.org/)

Encyclopédie vivante, versionnée, multi-langue.

| | |
|--|--|
| **Pour** | Commun ; NPOV ; infrastructure mentale mondiale |
| **Contre** | Guerre d’édition ; peu de « spectacle du désaccord » désirable ; slogans pas objets premiers |
| **↔ Magma** | **proche** de la piste wiki / science incrémentale ; Magma ajoute désaccord fécond explicite, slogans, art |

### [Wikiquote](https://www.wikiquote.org/)

Citations sourcées.

| | |
|--|--|
| **Pour** | Matériau phrases |
| **Contre** | Pas de dézippage critique structuré |
| **↔ Magma** | **partiel** — input pour un atlas, pas l’atlas |

## 4. Décision & participation institutionnelle

### [Loomio](https://www.loomio.com/)

Discussions + propositions + votes motivés (coopératives, orgs).

| | |
|--|--|
| **Pour** | Décider vraiment ; traçabilité des raisons |
| **Contre** | Orienté groupe fermé / org ; pas atlas culturel public |
| **↔ Magma** | **partiel** — brique « décision » ; un *outil Magma* dédié pourrait s’en inspirer |

### [Decidim](https://decidim.org/)

Participation citoyenne modulaire (processus, budgets, assemblées…) — open source.

| | |
|--|--|
| **Pour** | Mature ; institutions ; transparence |
| **Contre** | Lourd ; peu « empêcheur / fun » ; pas focus slogans |
| **↔ Magma** | **loin / partiel** — Magma n’a pas à refaire Decidim ; pont possible plus tard |

### [Consul Democracy](https://consuldemocracy.org/)

Propositions, débats, votes, budgets participatifs — open source (héritage Madrid).

| | |
|--|--|
| **Pour** | Éprouvé villes ; suite décisionnelle |
| **Contre** | Même famille « govtech » que Decidim ; peu transcendance / art |
| **↔ Magma** | **loin / partiel** — ne pas concurrencer frontalement |

## 5. Flux, annotation, notes communautaires

### [Hypothes.is](https://web.hypothes.is/)

Annotation web collaborative.

| | |
|--|--|
| **Pour** | Rencontre le texte *là où il est* |
| **Contre** | Pas une machine à penser complète |
| **↔ Magma** | **partiel** — piste « slogans dans le flux » / extension |

### Community Notes ([X / doc](https://communitynotes.x.com/guide/))

Notes contextuelles crowdsourcées sur posts.

| | |
|--|--|
| **Pour** | Contexte dans le flux ; bridging parfois |
| **Contre** | Captif d’une plateforme ; métriques sociales toxiques autour |
| **↔ Magma** | **partiel** — idée « déplier une phrase qui circule » ; Magma refuse le reste Twitter |

### Forums type [Discourse](https://www.discourse.org/)

Fils de discussion structurés.

| | |
|--|--|
| **Pour** | Communautés ; searchable |
| **Contre** | Fil = attracteur clash / digression |
| **↔ Magma** | **loin** comme cœur — le Brain évite le forum plat exprès |

## 6. Q&A & expertise (autre métier, même « question »)

### [Stack Overflow](https://stackoverflow.com/)

Q&A technique ; votes ; canon de réponses.

| | |
|--|--|
| **Pour** | Qualité par pairs ; gamification utile *dans un domaine vérifiable* |
| **Contre** | Échec relatif hors code ; toxicité ; pas valeurs / démocratie |
| **↔ Magma** | **loin** — apprend qu’un bon outil est **étroit** et excellent ; Magma = famille d’outils, pas un SO de la morale |

### Reddit / X (réseaux)

Débat de masse.

| | |
|--|--|
| **Pour** | Scale attention ; matériel slogans |
| **Contre** | Outrage, algorithmes, hommes de paille |
| **↔ Magma** | **loin** comme modèle — plutôt *antagoniste* ; Magma = empêcheur de tourner en rond |

## Lectures pour Magma (hypothèses)

1. **Ne pas refaire** Decidim/Consul sauf besoin gov clair.  
2. **S’inspirer fort** de Kialo (structure) + Pol.is (scale consensus) + Wikipédia (vivant).  
3. **Différenciation candidate** : slogans comme objets + steelman + art/fiction + jugement qualité + *plusieurs outils* (dont Weco).  
4. Stack Overflow rappelle : **étroitesse féconde** > monolithe moral.
