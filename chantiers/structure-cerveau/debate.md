# Débat — pipeline vs chantiers

- **Statut** : clos (option B tranchée) — gardé pour la mémoire du désaccord
- **Thèse** : pour un atelier à 2 + IA, mieux vaut découper par *chantier* que par *étape*.

## POUR les chantiers (steelman)

1. Un sujet éparpillé en 4 dossiers = **perte de fil** ; un dossier = fil visible.
2. L’absence de `map.md` crie plus fort qu’un dossier `syntheses/` vide qu’on n’ouvre jamais.
3. Compatible steelman / Git / humain décide — on change le *rangement*, pas l’éthique.

## POUR le pipeline (steelman)

1. Séparer les *natures* de travail (explorer ≠ cartographier ≠ décider) évite le mélange vaseux.
2. Force une maturité avant la formule — anti-slogan-orphelin.
3. Déjà adoptée (0001) ; migrer coûte cher en liens et en habitudes.

## Présupposés

- Qu’on peut migrer sans tout casser.
- Que « un sujet » est découpable (pas toujours vrai : sujets transverses).
