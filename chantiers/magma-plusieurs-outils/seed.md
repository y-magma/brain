# Seed — Magma n’est pas une app unique

- **Date** : 2026-07-27
- **Slogan** : « Pas un outil — une famille d’outils. »

## La tension

Le Brain regorge d’idées (atlas, spectacle, fiction, viz, science…).  
Les coller dans **un** produit = usine à gaz (et vanité).

**Magma** = projet parapluie : **beaucoup d’outils** pour **beaucoup de cas**.  
Chaque outil a un **nom** (ex. **Weco**) et ne catalyse qu’**une partie** des idées / slogans.

| Couche | Exemple |
|--------|---------|
| Idées Brain | « ralentir les slogans », « absurde désarme »… |
| Outil Magma | Weco (comparer graphes d’inégalités) |
| Exemple de question | « Faut-il supprimer le patrimoine ? » — adaptable selon l’outil |

## Faits / valeurs / hypothèses

- **Faits** : Weco existe déjà dans l’orga ; le Brain liste plus d’idées que Weco n’en porte.
- **Valeurs** : pour tous ≠ un monolithe ; clarté des frontières outil / idée / exemple.
- **Hypothèses** : une famille d’outils plats bat un super-outil qui fait tout mal.
