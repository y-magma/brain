# Débat — un Magma vs une famille

## POUR un seul outil Magma (steelman)

Une marque, une entrée, moins de dispersion ; le « pour tous » veut une porte unique.

## POUR une famille d’outils (steelman)

1. Les cas sont trop différents (viz data ≠ fiction ≠ atlas de slogans).  
2. Weco prouve qu’un outil **nommé** peut vivre sans tout absorber.  
3. Le Brain reste le lieu où les idées se croisent ; les outils **prélèvent**.

## Conciliation

Magma = **marque / intention** + catalogue d’outils ; Brain = atelier commun.
