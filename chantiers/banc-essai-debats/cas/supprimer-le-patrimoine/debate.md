# Débat — supprimer le patrimoine ?

- **Question** : [`question.md`](question.md)
- **Cadre** : patrimoine culturel / mémoire (sens 1) — sauf mention contraire

## Thèse A — Oui, il faut s’en libérer (steelman)

1. **Le patrimoine peut figer** : sacraliser le passé empêche d’inventer des formes vivantes (villes, rites, récits).
2. **Coût d’opportunité** : budgets monuments vs urgences présentes (logement, climat, soins).
3. **Pouvoir et exclusion** : « notre patrimoine » a souvent été celui des vainqueurs ; le garder tel quel perpétue une mémoire partielle.
4. **Désencombrer pour penser** : trop d’héritage symbolique = trop de tabous (lien avec questions qu’on refuse).

## Thèse B — Non, le supprimer serait une amputation (steelman)

1. **Mémoire = frein à la répétition** : sans traces, on recrée les mêmes violences / erreurs.
2. **Bien commun** : le patrimoine n’est pas que nostalgie ; c’est infrastructure culturelle partagée (savoir-faire, lieux, archives).
3. **Transmission ≠ dogme** : on peut hériter *et* critiquer ; détruire efface aussi les preuves pour juger le passé.
4. **Échelles** : ce qui est « poids mort » pour l’un est racines / réparation pour l’autre.

## Nuances

- « Supprimer » ≠ « critiquer » ≠ « transformer » ≠ « muséifier ».  
- Faux dilemme fréquent : tout garder vs tout raser.  
- Faits (coûts, fréquentation, destructions historiques) vs valeurs (continuité, justice mémorielle).

## Positions absentes à explorer

- Patrimoine **immatériel** (langues, gestes) vs pierre.  
- Qui décide de la destruction (État, marché, communauté locale) ?  
- Cas extrêmes (statues contestées) vs patrimoine du quotidien.
