# Question — Faut-il supprimer le patrimoine ?

- **Slug** : `supprimer-le-patrimoine`
- **Statut** : brouillon · cobaye Magma
- **Slogan / accroche** : « Faut-il supprimer le patrimoine ? »
- **Type** : débat de société (polémique utile pour tester l’outil)

## Ambiguïté assumée (à clarifier en session)

« Patrimoine » peut vouloir dire :

1. **Patrimoine culturel** — monuments, musées, mémoire collective.  
2. **Héritage économique** — transmission de richesse.  
3. **Héritage institutionnel** — règles / dogmes du passé.

Pour le banc d’essai, on démarre sur le sens **culturel + mémoire** (1), tout en notant que Magma devra **désambiguïser** la question avant de steeler — c’est déjà un test produit.

## Pourquoi ce cas

- Question courte, virale, émotionnelle — parfait pour atlas / spectacle / jugement.  
- Risque fort de homme de paille et de moraline → le steelman est difficile (bon stress-test).  
- Multi-échelle : individu / communauté / société / humanité.

## Ce que ce fichier n’est pas

Un avis d’Ariel ou Vincent. C’est un **matériau** pour voir si Magma aide à penser.
