# Débat — voir l’inégalité, est-ce déjà agir ?

- **Question** : [`question.md`](question.md)
- **Matériau** : Weco comme instance de visualisation

## Thèse A — Oui, rendre visible transforme (steelman)

1. **Sans image mentale, pas de débat public** : les g-percentiles / Lorenz restent abstraites ; Weco les rend navigables.
2. **Traçabilité** : montrer la source et les transformations (principe Weco) bat le slogan chiffré orphelin.
3. **Comparaison** : pays × temps × indicateurs = steelman empirique possible (« regarde cette courbe »).
4. **Porte Magma** : une URL Weco peut précéder un débat Brain — faits d’abord, camps ensuite.

## Thèse B — Non, visualiser peut servir d’alibi (steelman)

1. **Spectacle des écarts** sans levier politique = catharsis, pas changement.
2. **Qui lit les graphiques ?** Barrière cognitive / culturelle ; risque d’entre-soi expert.
3. **Choix de source et d’échelle** = déjà un cadrage idéologique (même transparent).
4. **Magma ne doit pas confondre** dashboard et démocratie : voir ≠ décider ensemble.

## Nuances

- Weco refuse la fusion silencieuse de concepts incompatibles — allié anti-sophisme.  
- Périmètre livré ≠ ambition recherche (éconophysique, etc.) : ne pas juger le produit sur le non-livré.  
- Pont possible : fiction absurde sur l’inégalité → puis « ouvre Weco » → puis débat Magma.

## Positions absentes

- Inégalités non monétaires (temps, soin, attention).  
- Public scolaire / citoyen vs chercheur.  
- Gouvernance des clés API / dépendance WID.
