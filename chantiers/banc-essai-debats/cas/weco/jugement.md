# Jugement — Magma + Weco

> Magma ne dit pas si l’inégalité est « trop haute ».  
> Il peut juger la **qualité du débat**, et **s’appuyer** sur Weco pour ancrer les faits.

## Dimensions (comme les autres cas)

| Dimension | Sur ce cas |
|-----------|------------|
| Clarté | « Inégalité » de quoi (revenu, patrimoine, quoi pré/post impôt) ? |
| Steelman A/B | Voir sans agir vs voir = déjà politique |
| Faits / valeurs / hypothèses | Courbe WID = fait tracé ; « injuste » = valeur |
| Faux dilemmes | Visualiser **ou** militer — souvent les deux en séquence |
| Angles morts | Non-monétaire, Sud global, illétrisme graphique |
| Température | Indignation vs curiosité analytique |

## Dimensions spécifiques Weco (test produit Magma)

| Dimension | Question outil |
|-----------|----------------|
| **Ancrage URL** | Le débat cite-t-il une vue Weco partageable (`?v=…`) ? |
| **Traçabilité source** | WID / OECD / WB — concepts compatibles ? |
| **Transfo visible** | Échelle log, agrégation — déclarées ou cachées ? |
| **Pont Brain ↔ Weco** | Lien relatif orga : repo + Pages `/weco/…` |

## Sorties candidates

1. Carte Magma + **embeds / liens** vers `/weco/exploration`, `/weco/temps`, etc.  
2. Score « débat chiffré » : affirmation sans source ↓ ; affirmation + URL Weco ↑.  
3. Refus de fusionner des séries non comparables (aligné principes Weco).

## Refuse

Verdict moral auto · popularité TikTok des écarts · chiffres sans source.
