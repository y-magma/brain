# Seed — fun tranchant, anti-pute-à-clic

- **Date** : 2026-07-25
- **Tranché par** : y-magma
- **Slogan** : « Empêcheur de tourner en rond — titiller, pas cliquer. »

## La tension

Un texte juste mais mort = personne ne le lit.  
Un texte vivant mais manipulateur = tout le monde le lit… et pourrit un peu.

On veut **apprendre en s’amusant** : révolutionnaire sans slide deck, transcendant *après* le concret, holistique sans soupe.

## Ce qu’on refuse

Le 10ᵉ argument qui « va vous surprendre ».  
Le cliffhanger à la place d’une phrase.  
L’outrage comme carburant.

## Faits / valeurs / hypothèses

- **Faits** : demande humaine explicite ; plaisir sain déjà exploré (archive).
- **Valeurs** : désirabilité de lecture + intégrité argumentative.
- **Hypothèses** : ton fun × steelman est tenable (à prouver sur la durée).
