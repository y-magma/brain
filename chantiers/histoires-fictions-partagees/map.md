# Map — Harari → outils Magma

## Convergences

| Point | Nature | Lien Magma / Brain |
|-------|--------|---------------------|
| Coopération large = récits partagés | hypothèse fertile (Harari) + observation banale | Désaccord public = collision d’histoires |
| Slogans = unités narratives | fait d’usage | [atlas-slogans](../atlas-slogans/) |
| Art / fiction désarme | valeur + hypothèse | [fiction-absurde](../fiction-absurde/) |
| Plusieurs outils ≠ un récit unique | valeur Magma | [multi-outils](../magma-plusieurs-outils/) |
| Faits restent traçables | valeur Brain | [Weco](../../outils/weco/) · faits/valeurs/hypothèses |

## Divergences assumées

| Tension | Camp A | Camp B |
|---------|--------|--------|
| Place du récit | Central : designer *pour* les histoires | Périphérique : d’abord arguments / data |
| Absurde | Porte noble | Risque de dilution « sérieux » |
| Harari | Boussole utile | Star intellectuelle → biais d’autorité |

## Angles morts

- Récits non verbaux (rituels, UX, algorithmes de feed) — Harari parle peu « produit ».
- Qui *écrit* l’histoire dans l’outil (IA, modération, communauté) ?
- Cultures où « fiction partagée » n’est pas le cadre mental dominant.
- Différence **mythe fondateur** vs **propagande de flux** (TikTok) — Magma doit préciser laquelle il traite.

## Heuristiques de design *(propositions, pas spec)*

Pour **chaque** futur outil Magma, se poser :

1. **Quelle fiction partagée** cet outil suppose déjà (nation, mérite, « le débat », science, marché…) ?
2. **Rend-il visible** le récit adverse en *steelman* — ou le caricature-t-il ?
3. **Ralentit-il** le slogan ou l’**accélère**-t-il (pute à clic) ?
4. **Sépare-t-il** fait / valeur / hypothèse — pour qu’« histoire » ≠ « mesure » ?
5. **Une porte** : un seul mode narratif (comparer, dueler, désarmer, déplier) — pas toute la mythologie humaine ([une-porte](../une-porte-pas-tout/)).

### Lecture par famille d’outils (exemples)

| Famille (idée) | Job narratif | Exemple existant |
|----------------|--------------|------------------|
| Viz / data | Ancrer ou *contredire* une histoire par des traces | **Weco** |
| Atlas / fiches | Déplier un mini-mythe (slogan) | chantier atlas |
| Spectacle / duel | Mettre deux histoires en scène (plaisir) | spectacle-désaccord |
| Fiction absurde | Montrer qu’on était dans une histoire | Vichnu / fiction-absurde |
| Jugement / map | Cartographier coalitions narratives | banc d’essai |

**Hypothèse :** un outil Magma « réussi » change le *statut* d’une histoire (croyance → objet comparable), pas seulement le score d’un camp.
