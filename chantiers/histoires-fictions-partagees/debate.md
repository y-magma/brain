# Débat — Harari comme boussole de design ?

## Steelman — oui, ça aide à designer

1. **Coopération = fiction commune**  
   Un outil Magma qui ignore les récits (et ne traite que « faits » ou « arguments ») rate le moteur réel du désaccord public.

2. **Les slogans sont des mini-mythes**  
   Une phrase courte recrute une coalition. L’[atlas](../atlas-slogans/) et le steelman deviennent des *instruments de lucidité narrative*, pas seulement de logique.

3. **Plusieurs fictions, plusieurs portes**  
   Cohérent avec [Magma = famille d’outils](../magma-plusieurs-outils/) : un outil ne porte pas *toutes* les histoires ; chacun catalyse un mode (viz, duel, absurde, fiche…).

4. **Danger nommé (Homo Deus / 21 Lessons)**  
   Qui contrôle les récits (et bientôt les modèles qui les génèrent) contrôle l’attention. Magma peut viser : **rendre le récit inspectable**, pas le remplacer en silence.

5. **L’absurde comme contre-fiction**  
   Pont [Vichnu / fiction-absurde](../fiction-absurde/) : une histoire décalée révèle qu’on était déjà *dans* une histoire — sans sermon.

## Steelman — méfiance utile

1. **Harari = vulgarisateur** — thèses discutées (archéologie, « révolution cognitive », universalisme). Les prendre comme *heuristiques de design*, pas comme science close.

2. **« Tout est fiction »** peut relativiser les faits (climat, inégalités). **Weco** et le fait/valeur/hypothèse du Brain sont le garde-fou : une fiction n’annule pas une mesure.

3. **Risque de méta-dogme** : « nous, on voit les histoires, eux non » = nouvelle élite narrative. Contredit [sans dogme](../questions-sans-dogme/).

4. **Storytelling produit** : utiliser Harari pour justifier du contenu addictif (« une belle story ») = exactement le populisme à éviter ([ton empêcheur](../../workflow/ton.md)).

## Conciliation candidate

Harari → **checklist de design**, pas bible.  
Chaque outil Magma se demande : *quelle fiction il active, quelle fiction il ralentit, et comment l’utilisateur voit la différence.*
