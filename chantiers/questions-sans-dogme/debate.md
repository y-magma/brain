# Débat — sans dogme vs sans boussole

- **Statut** : ouvert

## POUR le questionnement perpétuel (steelman)

1. Dogme = questions interdites = civilisation qui se définit par ce qu’elle *ne* pose pas (Malraux).
2. Une machine à penser qui ne peut pas se penser elle-même est un gadget.
3. Compatible avec un **petit** noyau *révisable* (Git + statut retiré).

## CONTRE le « tout questionner » absolu (steelman)

1. Sans aucun engagement, pas d’action collective — Magma devient café philo stérile.
2. « Pas de dogme » peut devenir dogme du relativisme (faux équilibre).
3. Certaines questions blessent ou manipulent ; liberté ≠ absence de garde-fous (steelman ≠ plateforme haine).

## Conciliation candidate

Questions **toujours ouvrables** ; réponses **provisoires** ; refus = **explicite** (on dit ce qu’on ne traite pas *pour l’instant*, et pourquoi).
