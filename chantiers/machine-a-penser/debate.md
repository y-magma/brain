# Débat — forme ouverte vs identité « slogans »

- **Statut** : ouvert (cadrage)

## POUR « slogans = tout le produit » (steelman)

1. Les phrases courtes sont l’unité de circulation réelle.
2. Focus = MVP possible (atlas) ; « forme ouverte » dilue.
3. Distiller force la clarté.

## POUR « porte, pas maison » (steelman)

1. Réduire Magma aux slogans tue les autres portes (spectacle, wiki science, IA/UX…).
2. Une piste rédigée (atlas) devient vite *la* définition par inertie.
3. Machine à penser = **questions** d’abord ; formules = outils, pas temple.

## Nature

Surtout **valeurs** + **hypothèse** produit.
