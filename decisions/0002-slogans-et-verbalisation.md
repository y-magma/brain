# 0002 — Slogans = brique ; peu de verbalisation

- **Date** : 2026-07-25
- **Statut** : adoptée
- **Décideurs** : y-magma
- **Remplace** : anciennes 0003 + 0004

## Décision

1. Slogans / expressions = **brique majeure** de Magma, pas le projet entier (« porte, pas maison »).
2. Chaque chantier porte une **accroche** dès le `seed.md`.
3. **Peu de verbalisation** : slogan d’abord ; puces ; liens ; budgets dans `AGENTS.md`.

## Conséquences

Clarté + risque de sloganisme — gardé en tension avec [`../chantiers/questions-sans-dogme/`](../chantiers/questions-sans-dogme/).
