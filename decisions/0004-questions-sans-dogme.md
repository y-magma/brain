# 0004 — Questions sans dogme

- **Date** : 2026-07-25
- **Statut** : adoptée
- **Décideurs** : y-magma
- **Sources** : [`../chantiers/questions-sans-dogme/`](../chantiers/questions-sans-dogme/) · Malraux (attribution usuelle)

## Contexte

Une civilisation se définit aussi par les questions qu’elle **ne** pose pas. Magma veut l’inverse opérationnel : pouvoir tout questionner, sans temple.

## Décision

1. Le Brain / Magma = **machine à questions** autant qu’à réponses.
2. **Pas de dogme** : tout axiome du noyau est révocable ; tout chantier rouuvrable.
3. Refus temporaire d’une question = **explicite** (motif), pas tabou muet.
4. Steelman des tabous ≠ endorsement ; garde-fous éditoriaux restent possibles.

## Conséquences

- Identité forte ; tension fertile avec le noyau.
- Risque relativisme — à tenir via faits/valeurs/hypothèses + cartes.
