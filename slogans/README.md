# Slogans

Les **idées fortes** distillées d'un consensus. Mémorables, oui — mais **jamais orphelines** : chaque slogan reste relié à son raisonnement et aux points de vue qu'il réconcilie.

> **Trois usages du mot « slogan » dans ce dépôt.**
> 1. **Accroche d'idée** (`idees/`) : formule obligatoire sur chaque graine (candidate, expression, phrase qui circule).
> 2. **Slogan distillé** (ici, `slogans/`) : consensus du collectif `brain`, avec raisonnement.
> 3. **Slogan-objet** (piste produit) : phrase qui circule dans la société, à déplier — une *brique* de la machine à penser, pas sa définition (voir [`../idees/2026-07-24-slogans-porte-pas-maison.md`](../idees/2026-07-24-slogans-porte-pas-maison.md)).

## Le noyau (axiomes)

Le sous-dossier [`noyau/`](noyau/) accueille l'ensemble **minimal** de formules adoptées comme boussole du collectif — multi-échelle, multi-granularité. Voir l'idée [`../idees/2026-07-24-noyau-axiomes-de-slogans.md`](../idees/2026-07-24-noyau-axiomes-de-slogans.md).

## Proposer un slogan

1. Copier [`_gabarit-slogan.md`](_gabarit-slogan.md).
2. Renommer en `titre-du-slogan.md` (ou le placer dans [`noyau/`](noyau/) si candidature d'axiome).
3. Remplir **rôle**, **échelle**, **granularité**, ouvrir une Pull Request.

## Le garde-fou anti-populisme

Un slogan sans raisonnement traçable n'est pas admis. On distille sans appauvrir : la formule choc doit pouvoir être « dézippée » jusqu'à la synthèse (ou au débat) qui la fonde. L'IA propose plusieurs formulations candidates ; les humains choisissent. Un *slogan candidat* sur une idée n'est **pas** un axiome du noyau.
