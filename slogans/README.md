# Slogans

Les **idées fortes** distillées d'un consensus. Mémorables, oui — mais **jamais orphelines** : chaque slogan reste relié à son raisonnement et aux points de vue qu'il réconcilie.

## Proposer un slogan

1. Copier [`_gabarit-slogan.md`](_gabarit-slogan.md).
2. Renommer en `titre-du-slogan.md`.
3. Remplir, ouvrir une Pull Request.

## Le garde-fou anti-populisme

Un slogan sans raisonnement traçable n'est pas admis. On distille sans appauvrir : la formule choc doit pouvoir être « dézippée » jusqu'à la synthèse qui la fonde. L'IA propose plusieurs formulations candidates ; les humains choisissent.
