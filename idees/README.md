# Idées

Les **graines** : problèmes, intuitions, propositions. C'est le point d'entrée du cycle (voir [`../workflow/processus.md`](../workflow/processus.md)).

## Déposer une idée

1. Copier [`_gabarit-idee.md`](_gabarit-idee.md).
2. Renommer en `AAAA-MM-JJ-titre-court.md` (ex. `2026-07-23-wikipedia-2-0.md`).
3. Remplir — **y compris le slogan / expression associée** — puis ouvrir une Pull Request.

Une idée n'est pas une conclusion : elle a le droit d'être floue, partielle, provocante. Elle mûrira dans [`../points-de-vue/`](../points-de-vue/).

## Slogan / expression associée (obligatoire)

Chaque idée porte une **formule courte** : slogan candidat, expression courante, proverbe, ou phrase qui circule déjà dans la société (même un peu stupide ou toxique, si c'est le matériau à penser).

Exemples de *genre* : « Travailler plus pour gagner plus », « Le travail rend libre », « Small is beautiful », « Savoir à qui parler ».

Ce n'est **pas** encore un slogan distillé du collectif (dossier [`../slogans/`](../slogans/)) : c'est une accroche, un exemple, ou une porte d'entrée mémorable pour la graine. Voir aussi la décision [`../decisions/0002-slogans-brique-et-accroche-des-idees.md`](../decisions/0002-slogans-brique-et-accroche-des-idees.md).
