# En clair — Brain, Magma, outils, exemples

> Une page. Point.

## Quatre choses — ne pas les coller

| | C’est quoi | Où |
|--|------------|-----|
| **Brain** | Atelier brainstorming (ce dépôt). Se structure. **Exemple** de méthode. | ici |
| **Magma** | Projet parapluie : **plusieurs outils** pour **plusieurs cas** (*pour tous*, plutôt plat). | intention |
| **Outil Magma** | Produit **nommé** (ex. **Weco**) qui catalyse *une partie* des idées — pas toutes. | [`../outils/`](../outils/) |
| **Exemple de question** | Débat cobaye (ex. patrimoine), **adaptable** à divers outils. | [`../chantiers/banc-essai-debats/cas/`](../chantiers/banc-essai-debats/cas/) |

```
          idées / slogans (Brain)
                 │
        ┌────────┼────────┐
        ▼        ▼        ▼
     Weco    (futur)   (futur)
     graphes  atlas?   fiction?
        │        │
        └──── exemples de questions (adaptés)
```

**Attention :** le Brain liste beaucoup d’idées. Magma ne les livre pas toutes dans un monolithe.  
Weco ≠ exemple de débat. Patrimoine ≠ outil.

---

## Workflow d’une idée **dans le Brain**

```
seed → debate → map → formula
```

Dossier = `chantiers/<sujet>/` *(convention atelier, pas UX Magma)*.

| Fichier | Question |
|---------|----------|
| `seed.md` | De quoi + slogan ? |
| `debate.md` | Meilleur pour / contre ? |
| `map.md` | Accords / désaccords / trous ? |
| `formula.md` | Quelle phrase garder ? |

IA : steele, cartographie, propose. **Ne décide pas** l’UX Magma.
